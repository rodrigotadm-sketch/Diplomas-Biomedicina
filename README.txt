DIPLOMAS-BIOMEDICINA V3
1. Envie index.html, styles.css, app.js e dados.json para a raiz do repositório Diplomas-Biomedicina.
2. Não é necessário publicar requerimento de RVDD: o novo fluxo é feito pelo SIGA/Acesso Externo.
3. Quando o tutorial oficial for publicado na Biblioteca de Mídia do WordPress, copie a URL para tutorial_url em dados.json.
4. O app.js possui fallback interno para os dados essenciais caso dados.json falhe.
5. O arquivo iframe-wordpress.txt contém o código de incorporação para a página institucional.
